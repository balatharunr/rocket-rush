# Fonts

This directory contains custom font files for the game UI.

## Contents

Place font files here such as:
- Custom display fonts for titles and headers
- UI fonts for menus and HUD
- Any other custom typography

## Recommended Formats

- WOFF2 for best compression and browser support
- WOFF as fallback
- TTF for broader compatibility if needed

## Naming Convention

Use descriptive, lowercase names with hyphens:
- `retro-arcade.woff2`
- `ui-display.woff2`
- `hud-mono.woff2`

Ensure all fonts have appropriate licenses for use in your project.
