# Game Assets

This directory contains all game assets including images, sounds, and fonts.

## Subdirectories

- `images/` - Game sprites, textures, and visual assets
- `sounds/` - Audio files for sound effects and music
- `fonts/` - Custom font files for the game UI

## Guidelines

- Use optimized file formats (WebP for images, MP3/OGG for audio)
- Keep file sizes reasonable for web performance
- Maintain consistent naming conventions
- Document asset sources and licenses if applicable
