# Sounds

This directory contains game audio assets.

## Contents

Place audio files here such as:
- Sound effects (shooting, explosions, pickups)
- Background music
- UI sounds (button clicks, notifications)
- Voice lines or dialogue

## Recommended Formats

- Use MP3 for broad compatibility
- Use OGG Vorbis as an alternative format
- Consider using both formats for maximum compatibility

## Naming Convention

Use descriptive, lowercase names with underscores:
- `shoot_laser.mp3`
- `explosion_large.mp3`
- `pickup_health.mp3`
- `music_level_1.mp3`
