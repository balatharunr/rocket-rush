# Images

This directory contains game image assets.

## Contents

Place image files here such as:
- Game sprites (player, enemies, bosses)
- Background textures
- UI elements and icons
- Particle effects
- Any other visual assets

## Recommended Formats

- Use WebP for best compression/quality balance
- Use PNG for transparency support
- Use SVG for scalable graphics when possible

## Naming Convention

Use descriptive, lowercase names with underscores or hyphens:
- `player_ship.png`
- `asteroid_large.png`
- `boss_bouldron.png`
