# Rocket Rush

A retro neon arcade space runner. Dodge, blast, and bomb cosmic threats.

## Play

Open `index.html` in any modern browser. No build step required.

## Controls

- **Move:** WASD / Arrow keys
- **Shoot:** J / Z / Left Click
- **Bomb:** B / X / Right Click
- **Turbo:** Space / Shift
- **Pause:** P
- **Mute:** M
- **Restart:** R

## Project Structure

- `index.html` - Main entry point
- `css/styles.css` - Styling and neon arcade theme
- `js/` - Game logic modules (vanilla JS, no bundler)
