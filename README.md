## ⚡ The Experience

**Rocket Rush** is a hyper-kinetic space runner where your reflexes are the only thing keeping you alive. Navigate through blinding neon chaos, obliterate incoming threats, and push your absolute limits in a relentless, endless arcade gauntlet. 

> **The Flex:** Built entirely from scratch with **zero frameworks, zero game engines, and zero libraries.** This project is a love letter to the raw rendering power of HTML5 `<canvas>` and vanilla JavaScript.

## 🕹️ Core Features

* **🚀 Razor-Sharp Controls:** Buttery smooth spaceship movement designed for twitch-reflex evasion.
* **💥 Real-Time Ballistics:** High-performance projectile tracking and collision detection.
* **💣 Tactical Bomb System:** Wipe the screen when the bullet hell gets too overwhelming.
* **⚡ Turbo Overdrive:** Clutch boost mechanics for narrow escapes.
* **👾 Infinite Scaling:** Endless enemy waves that dynamically increase in difficulty.
* **🎨 Synthwave Aesthetic:** Striking retro-neon visuals that glow straight out of the 80s arcades.
* **🔊 Immersive Audio:** Integrated SFX with instant mute controls for stealth playing.
* **🔁 Zero Downtime:** Instant restart loops and pause states to keep you in the zone.

## 🛠️ The Architecture

Who needs heavy dependencies when the browser is this powerful?

* **HTML5 Canvas API:** Handling 100% of the visual rendering, frame updates, and particle animations.
* **Vanilla JavaScript (ES6+):** Object-oriented game logic, physics engine, collision math, and game loop management (`requestAnimationFrame`).
* **CSS3:** Interface styling, neon glows, and responsive wrapper formatting.
